# DSA Lab in C

Interactive dashboard for eight Data Structures and Algorithms experiments in C.
Each experiment has the concept, a live visualizer, algorithm steps, a complete C program and viva questions.

1. Arrays, array of structures and pointers
2. Singly linked list
3. Stack using SLL and infix to postfix
4. Static queue (linear and circular)
5. Binary search tree using DLL nodes
6. Graph traversal (BFS and DFS)
7. Sorting and searching
8. Hash table (chaining and probing)

Plain HTML, CSS and JavaScript. Open `index.html` in a browser, no build step.
